Lenzo is an iOS app that allows learning languages in real time, anytime, anywhere. Swift Student Challenge 2026 Winner.

## Features
• On-device AI & live camera learning — Point the camera at real objects, hold to select, and Lenzo lifts and identifies what you tapped using Vision + Apple Intelligence. <br>
• Instant vocabulary cards — Get translations, phonetic guides, bilingual example sentences, and spoken audio for words you capture. <br>
• Your word lists — Create themed lists, save captures from the camera, star favorites, and remove items or whole lists with data stored on-device. <br>
• Practice games — Drill lists with flashcards, memory match, quizzes, and word scramble. <br>
• Real-world conversation practice — Roleplay common situations (café, hotel, taxi, and more) with a multi-turn AI partner, hints, suggested replies, and speech. <br>
• Made for your device & habits — Onboarding introduces the flow; settings cover appearance, haptics, and selection circle size, with a clear message if Apple Intelligence isn’t available. <br>

## Built With
Swift, SwiftUI, Apple Intelligence (on-device Foundation Models), Vision, AVFoundation

## Run / Download App
#### Install Xcode
Install the latest Xcode from the Mac App Store (or developer.apple.com). Open it once so it finishes installing components.

#### Open the project
Double-click the My App 2. swiftpm package (or in Xcode: File → Open and choose that folder).
You can also open it in Swift Playgrounds on Mac if you prefer that workflow.

#### Select a run destination
In the toolbar, pick an iPhone or iPad simulator, or a physical device connected with a trusted developer setup.

#### Signing (device only)
To run on a real iPhone/iPad, select the app target, open Signing & Capabilities, choose your Team, and let Xcode manage a development provisioning profile.

#### Build and run
Press ⌘R (or click Run). Xcode builds the app and installs it on the chosen simulator or device. If you are using a physical device, make sure it is plugged into your Mac via USB-C
The app targets iOS 26+ and uses Apple Intelligence for on‑device AI. For full behavior, run on a supported device (as in the app’s requirements screen), not only an older simulator.
